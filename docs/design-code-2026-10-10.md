# Дизайн-код mox-studio.ru для MOX Access (2026-10-10)

Снято с живого сайта (Playwright, главная и /projects, 1440px), сверено с `mox-site` и скиллами
`mox-web-page` / `mox-tech-proposal-page`. **[сайт]** — проверено на сайте, **[скилл]** — из скиллов.

## Палитра

- Фон `#222222` [сайт, скилл `--bg`]; самые тёмные секции `#111111`, `#0E0E0E` [сайт].
- Поверхности: `#2A2A2A` hover строк [скилл], `#313131` [сайт = скилл], `#333333` pill-кнопки [сайт],
  `#494949` hover pill [сайт].
- Текст: `#EEEEEE` / `#989898` / `#717171` [сайт = скилл]; самый тихий `#494949`.
- Акцент мятный `#8ADDD4` — точечно: точка в конце заголовка, номера, точка-статус у кнопки [сайт];
  hover `#66ADA4`.
- Тёплый `#F5C97A` — «здесь решает человек», он же ошибки [скилл]. Красного нет нигде.
- Статусы приложения (вывод): ok — мятный, warn/error — тёплый, idle — `#717171`.

## Типографика

- Inter Tight Regular почти везде [сайт]. В Tilda семейство `Monts` с весом 900 указывает на
  InterTight-Regular — в приложении писать 400, не 900. Файлы — `mox-site/public/fonts/tilda/`.
- JetBrains Mono — стиль документов [скилл], на сайте нет; в приложении — только технические значения.
- Шкала сайта: заголовок 42/50 `-1px` в две краски, карточка 24/29, подзаголовок 19/25, текст 12,
  кнопки 12–14 ЗАГЛАВНЫМИ.
- Для окна 760px: заголовок 28/1.15 400–500 `-0.015em`, текст 14/1.5, подписи 12, моно 12–13 `tabular-nums`.

## Компоненты

- Primary: pill 40px, фон `#333`, текст `#EEE` 12px ЗАГЛАВНЫМИ, hover `#494949`, 0.2s; мятная точка
  10.7px слева — статус [сайт]. Вариант скилла: фон `#2C3534`, текст мятный, hover — мятная заливка.
- Ghost: прозрачный, `#717171`, hover `#313131` [скилл]. Иконка-кнопка: круг 40, `#333` [сайт].
- Карточки: r20, без обводки и теней [сайт]. Поля: фон `#313131`, r12, фокус — рамка
  `rgba(255,255,255,.26)`, мятный только `caret-color` [скилл].
- Разделители `rgba(255,255,255,.06)`/`.12`. Строка ключ-значение: ключ моно 11 ЗАГЛАВНЫМИ `#717171`.
- Бейдж статуса: точка-индикатор + текст.

## Характер и запреты

Тёмный минимализм на графите, крупный тонкий гротеск, две краски, мятный как пунктуация, много воздуха,
pill и r20, вес не выше 500. Тон — инженерная констатация.
Нельзя: белый/чёрный фон, градиенты, тени, стекло, обводки плашек, мятная рамка фокуса, 700+, новые
оттенки, красный/синий, моно в обычном тексте, восклицания, эмодзи.
