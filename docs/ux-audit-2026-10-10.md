## Проблемы

- Нет вердикта; жёлтая primary — всегда «Выключить» (`index.html:18-26,53`). Версия дважды. Обновление — красным, как ошибка.
- Журнал открыт всем, старое сверху, без автопрокрутки. «Как подключиться» — всегда, шаг 2 только про macOS.
- Терминология: «корпоративный» / «рабочий» / «MOX» про одно; «туннель», «harness», «ключ MOX», «vps6» (`tray.go:39`);
  «ты» вперемешку с «вы» (`update.go:89`, `main.go:75,97`); «Выйти» в кольце путается с «Выйти» в Codex (тот отзывает ключ).
- Ошибки — серая строка без `aria-live` (`index.html:32,56`), сырые тексты ОС (`app.go:159`); основной канал ошибок —
  системное уведомление, которое на маке у неподписанного приложения может не показаться.
- Импорта `.moxaccess` и «Войти в GitHub» в окне нет, хотя окно их требует / онбординг считает шагом.
- Опасное без предупреждения: включение/выключение и «Обновить набор» перезапускают Codex (`app.go:243,286`, `actions.go:204`);
  подтверждение переноса только в окне; перенос на Windows ломается постфактум.
- Windows: подсказка «выйдите из Windows» есть только в трее, не в `/api/status` (`web.go:68,106`).
- Долгие операции — статичное «Переношу…» до 30 минут; трей не показывает занятость.
- Мелкий текст 12–13px; окно — вкладка браузера на случайном порту.

## Рекомендации

**Окно:** (1) статус-баннер с одной кнопкой «Исправить»; приоритет причин: нет файла → доступ отозван → перелогин
Windows → нет связи → вход сбился → обновление (инфо); (2) действия: GitHub, правила команды, перенос (скрыт на
Windows), обновление; вкл/выкл — переключатель, не primary; (3) «Доступы к сервисам»; (4) «Для поддержки» свёрнуто:
версии, журнал (новое снизу), «Скопировать для поддержки»; (5) «Как подключиться» — только до первой настройки.

**Трей:** статус, переключатель, «Вышла новая версия» (когда есть), «Открыть окно…», «Закрыть MOX Access».

**Словарь:** «Рабочий Codex: включён · [Выключить]»; «Нет связи с рабочим Codex. Проверьте интернет и VPN —
приложение повторяет попытку само»; «Доступ отозван. Напишите Денису — он выдаст новый файл»; «Правила и
скиллы команды»; «Вход в Codex сбился — возвращаю рабочий, до минуты»; «Codex перезапустится — дождитесь
конца ответа»; везде «вы».

**P0:** проверка отзыва ключа + заметный отзыв; Windows-перелогин в окне; предупреждение о перезапуске Codex;
вердикт с «Исправить» и импорт в окне; ошибки красным блоком с `aria-live`, человеческим текстом.
**P1:** словарь, GitHub в окне, прогресс, «Для поддержки», версия набора, фиксированный адрес окна.
**P2:** «Доступы к сервисам» (нужен до первого ключа Тильды), drag-and-drop, светлая тема, крупнее мелкий текст.

Не проверено: Windows вживую, уведомления неподписанной сборки. Проверить на Лиле или Динаре.
