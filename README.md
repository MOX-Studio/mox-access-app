# MOX Access

**Рабочая область команды:** приложение и набор MOX создают `~/AI` (Windows:
`%USERPROFILE%\\AI`). Главная инструкция — `~/AI/AGENTS.md`; Claude импортирует
её через `~/AI/CLAUDE.md`, Codex читает служебное зеркало в `~/.codex/AGENTS.md`.
Репозитории находятся в `~/AI/Project/MOX` и `~/AI/Project/Personal`.
«Обновить набор MOX» переносит старые локальные проекты и обновляет пути тредов.
Проект без GitHub origin переносится автоматически только при явной пометке «Личная песочница» в README; неоднозначный проект останавливает перенос до определения владельца.
Служебные каталоги клиентов остаются на штатных местах.

Приложение для сотрудников MOX Studio: одна кнопка «корпоративный Codex вкл/выкл». Держит туннель к шлюзу MOX ACCESS,
переносит треды и проекты с сервера, подключает набор команды (правила, скиллы, MCP).

**Установка (macOS):** скачайте `MOX-Access-mac-arm64.zip` (Apple Silicon) или `-amd64` (Intel) из
[Releases](../../releases), распакуйте, перенесите `MOX Access.app` в «Программы», откройте **правым кликом → Открыть**
(приложение не нотаризовано). В строке меню появится «MOX». Дальше: «Импортировать .moxaccess…» (файл от Дениса) →
«Корпоративный Codex: включить». macOS один раз попросит пароль — доверие сертификату шлюза.

**Что делает «включить»:** сертификат шлюза → вход MOX вместо личного (личный сохраняется) → строки MOX в `~/.codex/config.toml`
→ переменные окружения Codex (launchd) → туннель `localhost:8000` → перезапуск Codex → проверка ключа через шлюз.
«Выключить» — то же в обратном порядке, личный вход возвращается.

**Сборка:** `go test ./... && build/mac.sh` (нужны Go ≥ 1.27 и Xcode Command Line Tools); Windows — `build/windows.sh` с любой машины. Ключей, адресов и секретов в репо нет —
всё приходит в `.moxaccess`. Тег `v*` собирает релиз через GitHub Actions.

**Windows (предварительная сборка, с 0.3.0):** `MOX-Access-windows-amd64.zip` (`arm64` для Windows on ARM) из Releases, распаковать,
запустить `MOX Access.exe` (SmartScreen: «Подробнее» → «Выполнить в любом случае»), значок в трее у часов. Те же шаги, что на маке,
с одним отличием: после «включить» и «выключить» нужно выйти из Windows и войти снова — приложение ChatGPT из пакета читает
переменные окружения только при входе (спайк S3 ищет обход). Перенос с сервера на Windows не поддерживается (не нужен).
Проверяется на первой Windows-машине команды; до этого сборка не выдаётся сотрудникам.
